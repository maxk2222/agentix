Implementierung in HTML

📚 Weitere Beispiele

Beispiel 1: Minimal Setup

const chat = new AgentixChatWidget.ChatWidget({ apiKey: 'sk-...' });

Beispiel 2: Mit Custom Prompt

window.initAgentixChat({ apiKey: 'sk-...', systemPrompt: 'Du bist ein Cybersecurity-Experte...', theme: 'light', position: 'top-left' });

Beispiel 3: Mit Error Handler

const chat = new AgentixChatWidget.ChatWidget({ apiKey: 'sk-...', onError: (error) => { console.error('Chat Error:', error); }, onInit: () => { console.log('Chat initialized!'); } });
