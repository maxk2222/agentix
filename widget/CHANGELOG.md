# Agentix CyberChatbot Widget - Changelog

## Version 1.0.0 (Initial Release)

### ✨ Features
- Modern, responsive chat widget for websites
- Real-time streaming from OpenAI API
- Markdown rendering support
- Dark and light theme
- Message history with localStorage
- Configurable position and size
- Multiple OpenAI models support
- Custom system prompts
- Error handling and retry logic
- TypeScript with full type safety

### 🔒 Security
- XSS prevention through input sanitization
- Secure API key handling

- Rate limiting capabilities
- Content Security Policy compatible

- Smooth animations and transitions
- Auto-scrolling to latest messages
- Textarea auto-resize
- Loading and error states
- Unread message badge
- Responsive for mobile devices
- Accessibility (ARIA labels)

- Simple initialization API

- Troubleshooting section
